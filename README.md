# Спринт · Курьер — концепт UI

Учебный/портфолио-проект: **оригинальный** дизайн-концепт интерфейса курьерского
приложения на Flutter.

> ⚠️ **Это не функциональный продукт.** Нет бэкенда, нет авторизации, нет реальной
> логистики, платежей или начислений. Все данные (заказы, слоты, история, выплаты,
> ответы поддержки) — захардкоженные моки в `lib/data/store.dart`, которые сбрасываются
> при перезапуске приложения. Камера, сканер штрихкодов и построение маршрута по
> дорогам работают по-настоящему (это нативные системные возможности устройства и
> публичные бесплатные сервисы), но результат никуда не сохраняется и ни на что
> не влияет, кроме локального состояния экрана. Рассматривайте проект как витрину
> UI/UX-решений, а не как рабочий сервис.

> Проект самостоятельный и ни с кем не аффилирован. Бренд «Спринт», логотип, палитра
> и вёрстка экранов придуманы с нуля. Никаких чужих логотипов, макетов или ресурсов.

## Что внутри

- **Вход** — телефон + код по SMS. Полностью имитация: код принимается любой,
  реальная SMS никуда не отправляется.
- **Заказы** — авто-назначение (без «принять/отклонить»), статус линии
  (слот / Биржа / пауза), несколько активных заказов одновременно, очередь,
  статистика дня.
- **Карточка заказа** — прогресс статусов, условия доставки (у двери, 18+,
  горячее и т.д.), состав, доплаты, таймеры забора/передачи.
- **Маршрут** — настоящая карта (`flutter_map` + тайлы CartoDB) с прокладкой
  маршрута по дорогам через публичный OSRM. Показывает актуальную дорожную
  ситуацию, но координаты курьера/точек — заданы в коде, не GPS.
- **Сканер пакетов** — настоящая камера устройства (`mobile_scanner`), распознаёт
  реальные QR/штрихкоды, но подтверждение никуда не отправляется — только в
  локальный стор.
- **Фото доставки** — настоящая камера (`image_picker`), снимки хранятся в памяти
  экрана и теряются при выходе.
- **Слоты** — недельное планирование по закреплённым полигонам (мок-данные).
- **Акции**, **История заказов**, **Уведомления**, **Чат/поддержка** — статичные
  списки и заглушки с эффектом «ответа» через `Future.delayed`.
- **Профиль** — личные данные, документы, настройки уведомлений, переключатель
  темы (светлая/тёмная/системная).

## Стек

- Flutter 3.44 / Dart 3, Material 3, кастомная дизайн-система (`lib/app/theme.dart`)
- Состояние — `ChangeNotifier` + `ListenableBuilder`, без DI/BLoC
- `flutter_map` + `latlong2` — карта; `http` — запрос маршрута к OSRM
- `mobile_scanner` — сканирование штрихкодов; `image_picker` — камера
- `url_launcher` — открытие внешних навигаторов
- `google_fonts` — шрифт Rubik
- Бэкенда нет: единственный сетевой трафик — тайлы карты и маршрутизация OSRM

## Структура

```
lib/
  app/theme.dart              — палитра, типографика, общие стили
  core/routing.dart           — обёртка над OSRM
  core/notifications.dart     — имитация push-баннеров
  data/models.dart            — модели (заказ, слот, уведомление, курьер…)
  data/store.dart             — мок-стор (ChangeNotifier), вся «база данных» приложения
  widgets/common.dart         — кнопки, логотип, hold-кнопка, ввод кода, таймеры
  features/
    auth/                     — вход по телефону/коду
    shell/home_shell.dart     — нижняя навигация
    orders/                   — список + детали заказа, общие действия
    map/route_page.dart       — карта и построение маршрута
    delivery/                 — сканер пакетов, фото доставки
    slots/                    — планирование слотов
    promos/                   — акции и бонусы
    history/                  — история заказов
    notifications/            — центр уведомлений
    chat/                     — чат с клиентом и поддержкой
    profile/                  — профиль, личные данные
```

## Запуск

```bash
flutter pub get
flutter run                 # устройство/эмулятор
flutter run -d chrome       # в браузере
flutter build apk --release
```

Для карты и маршрутов нужен интернет; без сети маршрут покажет пунктирную
прямую линию вместо прокладки по дорогам.
